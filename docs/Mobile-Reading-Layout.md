# 手机阅读布局

以确认后的白底聊天方案为主，配套工作空间侧栏；保留顶部连接端切换、合并操作记录及待回答入口。

## 交互

- 顶部仅保留会话标题、连接端下拉、状态灯/文字、侧栏与新建入口。长标题及连接名限制宽度。
- 侧栏提供搜索、按完整工作目录分组的会话、分组折叠、当前会话高亮、刷新、连接管理、设置。不同目录即使同名也独立分组，辅助描述保留完整路径。
- 切换连接端复用现有连接池及草稿保存逻辑，不关闭其他设备。
- 输入区整行编辑，下面是附件、模型、思考强度、按住说话与发送/停止。模型和思考强度入口均打开远端模型设置页；未查询的强度不假定为 High。
- 执行中无可发送草稿时显示停止；有可发送草稿时显示发送，保留追加消息能力。提交结果未知时优先显示核对入口。
- 只有存在待处理问题/审批时显示待回答/待确认；沿用原请求 ID 和提交链路，按远端返回状态刷新。
- 常规同步成功文字不再常驻，错误、缓存、连接恢复、语音和传输进度仍显示。完整状态、路径、流量移入会话详情。
- 助手正文无外层卡片、无重复产品名；复制入口保留。连续工具/推理/系统记录按原顺序合并，外层及单项均可展开；增量渲染保留展开状态。
- 操作条目显示记录数量，不从文本推断“执行成功”。分页边界仅显示当前已加载的记录。

## 接入端兼容

手机通过 `history-mode` 请求 version 2。新接入端提供包含操作与截断详情的有界分页；version 1 及未协商客户端保持原正文分页行为。

旧接入端忽略 version 2 时仍能显示正文和问题，但它已经过滤掉的工具记录无法在手机恢复。因此操作记录功能需要同时更新 Host；本次仅修改源码，没有自动部署服务器或安装客户端。
