# 多端连接与短固定码 0.9.1

2026-10-10。手机、电脑可用同一固定码同时连接同一接入端，无需控制权接管。每台接入端最多同时连接 8 个控制端；旧项目仍只作功能参考。

## 使用行为

- 各端独立选择会话。手机查看会话 B，不改变电脑正在操作的会话 A。
- 同一会话由 Host 保存唯一的适配器和运行状态。来自各端的操作在会话级串行提交；Agent 接受后即释放提交锁，不等待任务结束。运行中的新消息遵循原适配器的追加、排队或打断能力，不强行把所有后端视作同一种执行方式。
- 同一会话的快照向所有订阅端同步，各连接分别维护增量基线和 RPC 响应。模型、停止、审批等仍受 Agent 自身能力限制。
- 同一审批 ID 在 Host 中先占位，再向 Agent 提交。其他端立即移除入口；同时点击只接受一次。结果未知时保留占位，不自动重试审批，需在远端核对。
- 一端断开不会销毁会话适配器或停止任务；全部端断开后，Host 仍保留运行和未知提交状态，方便重新连接。停止共享才清理 Host 资源。
- 请求不因重连自动重放。两端各发一次同样内容仍是两次用户操作，不按文本去重；没有增加跨进程永久请求账本。

接入端保留最多 128 个访问过的会话适配器，避免为了回收缓存而中断运行或丢失待确认状态。达到上限后需在任务结束后重启接入端释放资源。

## 固定码

固定码缩短为 8 位，按 `ABCD-EF12` 显示，支持不带连字符、含空格及小写输入。由现有设备身份稳定派生，普通升级、接入端重启和中继重启不会再换码。

保留原 32 位固定码作为配对别名，旧保存连接可继续使用。主机身份密钥仍为 256 位，发生短码碰撞时拒绝注册而不覆盖既有设备。当前协议仍允许知道设备码的客户端操作；配对接口保留限流和一次性短期票据。
