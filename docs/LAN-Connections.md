# 局域网优先连接（Core 0.14.12 / Android 0.12.5）

Codex 接入端、桌面共享接入端及桌面/手机连接端共用实现。保留现有服务器地址和授权码，首次通过 HTTPS 中继配对并取得设备证书指纹和随机直连凭据；随后优先局域网连接。首次配对需要中继，已配对的客户端可在中继离线时连接，固定身份接入端也可在中继离线时启动。

局域网使用 IPv4 UDP 45371 发现（多播、广播及本机探测），TCP 45984–45999 传输。发现报文只带随机请求编号、证书指纹和端口，不公布授权码或访问凭据。TCP 使用 TLS 1.2/1.3、固定证书指纹校验和独立 256 位凭据；未认证请求限制为 4 KiB，接入限制 8 个直连并发。证书保存在设备身份文件旁的 `.lan.pfx`，升级必须保留；客户端凭据存于用户应用资料目录，Windows 用当前用户 DPAPI 加密，Android 存于应用私有目录。

局域网断开后自动选择直连或原中继；中继连接每 15 秒在空闲时尝试升级局域网。切换前恢复原会话和历史协议，原请求未结束或选择发生变化时推迟切换；已捕获的旧 RPC 引用转交新连接，消息、附件及审批不自动重放。直连时停止中继 HTTP 心跳探测，界面连接状态及会话详情显示连接方式。

Windows 需放行接入端程序的局域网入站连接。管理员执行 `scripts/Enable-LanFirewall.ps1`，默认读取 `FurtherAgent-Codex-Host` 的程序路径，仅为该程序、上述端口和本地子网添加规则，兼容被 Windows 归类为公共网络的家庭 Wi-Fi。桌面客户端开启共享时可用 `-ProgramPath 客户端完整路径` 添加对应规则。路由器设备隔离、广播过滤或防火墙阻拦时继续走中继。

可在接入端启动前设置 `FURTHERAGENT_LAN=0` 禁用局域网监听。没有固定身份的旧式临时接入端继续使用中继。旧接入端未提供 `lan-info` 时，新版客户端回退原中继连接。
