# 0.6.1 消息展示与托盘优化

日期：2026-10-09。

## 原会话诊断

通过后台 CLI 读取用户指定的最新会话，仅统计角色和必要字段：一条用户消息、一条非空 assistant 正式回复、一条工具返回，以及残留的 tool.started、tool.completed、reasoning.available 事件。reasoning.available 的内容与正式回复相近，被旧版 UI 作为普通大气泡展开，造成回复两次的观感。未发现这条会话有两条用户提交或两条正式回复。

用户气泡中的文件工作区说明由 FurtherAgent 文件传输层附加，供 Agent 交付文件使用。历史仍保留执行时原文；新展示层仅对符合已知生成格式、包含合法会话哈希 outbox 路径的用户消息尾部作显示投影。普通用户自行输入的标记不隐藏，AI 正文不处理，附件保留文件名。没有删除服务器会话历史。

## 实现

- 用户消息浅绿色并右侧排列，AI 正文白色；工具灰色、思考紫色并明确标注“非正式回复”。
- 工具和思考默认折叠，展开后的文本可选取、滚动，最大高度 240。历史工具参数与返回值不再整块铺开。
- 运行完成后以正式历史替换流式正文，清理重复的临时工具事件；思考事件单独分类，避免冒充第二条正式回复。没有按文本相似度删除真实 AI 回复。
- 输入区按钮统一 30 高度，减小边距；空附件说明不占位。右上角复制/归档同一尺寸样式。
- 关闭按钮隐藏到托盘并保留连接；双击托盘或再次打开桌面快捷方式恢复已有实例；托盘菜单“退出”断开并退出。Windows 注销/关机不被隐藏逻辑拦截。
