# 0.10.0 多连接与 Android 附件修复

2026-10-12。

桌面 0.10.1 补充：在已保存连接下拉框旁提供「＋ 新增连接」。点击后退出当前选中项，清空名称和授权码，保留中继地址并聚焦名称输入；保存另一台设备时保留原连接，当前已建立的连接不受编辑影响。Android 仍为 0.10.0，原本已有新增入口。

## 使用变化

- Android「连接」页可以命名、新增、保存、选择、修改和删除连接。同一中继下的多个设备分别保存；当前一次连接一个设备，切换不会停止远端任务。授权资料整体存入 Android SecureStorage，原单连接配置在首次读取时迁移，迁移失败保留原记录。
- Windows「连接设备」增加已保存连接列表、名称、保存和删除所选项；授权码继续使用当前 Windows 用户的 DPAPI 加密。兼容旧的单连接 JSON，连接成功后将该设备作为自动连接目标。
- FurtherAgent 的用户气泡和复制文本隐藏已识别的自动文件工作区说明，同时保留附件名。修复 Codex 用户角色为「你」而未进入显示过滤的问题。原始 Codex 历史、发给 Agent 的文件路径和输出目录说明保留。
- 手机打开、恢复或刷新会话时主动查询输出文件。正文底部显示可点击的文件卡片，附件菜单也可重新查询。旧接入端省略文件字段的后续快照不会覆盖已查到的列表；新版接入端为 Codex 等支持文件的 Agent 补齐输出列表。
- 下载先写临时文件，完成 SHA256 验证后交付；显示百分比、大小、平均速度。下载期间附件按钮变为取消，取消清理临时文件。成功后可选择打开，或通过系统保存/分享。
