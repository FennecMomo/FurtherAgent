# 0.14.11 迷你窗口快捷键

默认 Alt+P，使用 Windows 全局热键注册并禁用按住连发。大窗口按下后进入迷你模式；迷你模式与右下角小球相互切换。程序退出时释放注册。

设置页“迷你窗口快捷键”中按下新组合键，再保存。组合必须包含 Ctrl 或 Alt；先注册新键、保存文件，再释放旧键。冲突或写入失败时保留旧键。配置保存在用户目录 compact-hotkey.txt。
