# 同时连接多个设备（2026-10-13）

手机端和桌面端现在区分“保持连接的设备”与“当前查看的设备”。连接第二台设备不再释放第一台的连接；两台设备可以分别运行 Codex、Hermes 或其他已支持的 Agent。

## 使用

1. 按原来的方式连接第一台设备，再到连接页面选择或新增另一台设备并连接。
2. 桌面侧栏、手机主页顶部显示已连接设备选择框，包含设备名称和当前状态。选择设备即可回到它上次查看的会话。
3. 切换复用已经建立的连接，不重新配对。其他设备继续接收会话更新、保留重连逻辑和心跳；切回来可以看到其最新状态。
4. 手动断开仅关闭当前查看的设备，剩余连接继续工作。程序真正退出时统一关闭全部连接。

桌面窗口右上角关闭按钮仍按既有行为收进托盘，保持连接；使用托盘菜单“退出”才真正退出。手机切到其他应用属于后台运行，继续沿用前台连接服务及返回应用时的恢复检查。操作系统强制回收进程、网络中断等仍可能导致断线。

这里的“断开/退出”只结束 FurtherAgent 客户端连接，不向远端任务发送停止指令。要停止 Agent 任务仍使用会话中的停止按钮。

## 状态隔离

- 连接按规范化中继地址和授权码识别，同一设备重复连接复用原对象，不重复建立控制端。
- 每台设备保留自己的会话、消息、运行状态与连接诊断；相同会话 ID 不跨设备混合。
- 切换保留消息草稿、待发送附件；手机旧版草稿按原设备作用域迁移到稳定设备标识。
- 手机每台设备独立保留“提交结果未知”状态，不因切换、恢复或另一台设备成功发送而清除，也不自动重发。
- 新增设备连接失败不释放旧连接。传输文件、提交命令等正在等待确认时阻止切换，避免把后续操作指向另一台设备。
- 离线预览不再断开其他已连接设备，可从主页选择框切回。

保留原有保存配置与启动行为；本次没有新增启动时自动连接全部已保存设备的策略。设备连接由用户主动建立，实际退出后释放。
