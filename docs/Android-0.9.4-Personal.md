# Android 0.9.4 自用语音版

按用户要求，在自用 APK 中内置已通过真实 Fun-ASR 联调的 Key，安装后打开会话即可语音输入。密钥本身不进入 Git。内置资源可从 APK 提取，因此此交付仅用于用户自用。

构建通过 `scripts/Publish-Android.ps1 -PersonalSpeechKeyFile <本机密钥文件路径>` 显式启用。仅将一个 Key 放入文件，参数传文件路径而不是凭据内容。省略该参数的普通构建不包含内置密钥。本机文件放在已忽略的 `artifacts/private`，并限制为当前 Windows 用户访问。

运行时优先使用手机安全存储中的自定义 Key，未配置时使用 APK 内置 Key。设置页说明内置状态，并允许替换。“删除语音密钥”同时停用内置回退，不会在重新打开页面时自动恢复；“使用内置密钥”恢复内置 Key 和默认北京公共地址。APK 内的资源不会因停用而物理删除。

版本号 0.9.4 / 904，沿用开发签名，可覆盖安装 0.9.3。语音协议、录音与草稿处理不变。

验证：Release 构建与 APK 签名校验成功，编译程序集的内置资源与本机配置一致；Android 11 模拟器覆盖安装后未输入 Key，设置页显示密钥就绪。删除后重新打开仍保持未配置状态，点击“使用内置密钥”恢复。崩溃日志为空；Git 暂存内容检查不含密钥。

前一轮真实 API 联调：8.565 秒合成中文音频，识别文字完全一致，16 次文字更新；首次文字在开始上传约 0.79 秒后返回，音频上传结束到任务完成约 0.57 秒。此为电脑网络下的一次测量，不是手机性能保证。
