# 手机后台连接与双端状态提示（未打包）

## 修改

- Android 连接时启动 `remoteMessaging` 前台服务，主动断开或关闭窗口时停止；后台停止刷新 WebView，但继续接收会话数据。通知点击返回现有 Activity，避免新建空白连接页面。
- 返回前台先用只读 `agents` 请求检查原连接，最多等待 4 秒。健康连接直接复用；失效连接中止旧 socket 并唤醒已有重连流程，不必等退避计时结束。重连保留所选会话；不自动重发消息、附件或审批，保留发送结果不确定的保护。
- 手机输入框上方四个按钮下增加 10 号小字：附件、模型、停止、确认。下载中显示“取消下载”，有问题时显示“回答”和数量。
- 手机标题区域、桌面会话顶部增加同一套颜色与文字状态：红色断连、黄色连接中、蓝色执行中、绿色空闲。等待确认用黄色；没有所选会话或状态未知用灰色，避免把未知状态误报为空闲。桌面的 Codex 和原始风格均显示。
- 手机品牌区域版本号改为读取应用版本，消除固定旧版本文字。
