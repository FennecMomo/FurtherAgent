# 桌面历史上翻与手机输入区遮挡修正

## 桌面历史

桌面原先只渲染接入端提供的最新消息快照，没有调用已有的历史分页接口；正文 RichTextBox 还可能吞掉外层滚轮事件。

- 上滚到顶部自动请求前一页，也可点击“加载更早记录”。
- 追加历史时保留原消息的位置；阅读旧记录时实时状态和待回答继续更新，不覆盖阅读窗口。
- “返回最新”恢复最新快照。历史版本变化时保留阅读位置并提示重新返回最新。
- 请求去重，设备和会话切换后丢弃旧响应；每个设备分别保存阅读状态。
- 仅渲染最多 256 条，继续向前翻时移除尾部记录，避免长会话无限堆积控件。
- 使用已有 history 接口，本次桌面修正不要求更新接入端。

## 手机输入区

重构后的输入面板已有背景，但外围区域仍透明。补充整个底部输入区和编辑器的浅色/深色实底，明确前后层级，并裁剪正文 WebView 容器。保留键盘 AdjustResize 行为。
