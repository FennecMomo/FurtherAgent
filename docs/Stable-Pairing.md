# 固定配对码（0.6.0）

WPF 本机共享与 Linux Host 默认保存设备身份，注册时提交 256 位随机设备密钥，中继由带版本前缀的 SHA256 摘要取前 128 位生成 32 位十六进制配对码。拥有配对码只能走原有配对流程，不能反推出设备密钥来冒充接入端。

中继保留原有短期设备/票据生命周期，不需要新增磁盘数据库：身份文件留在接入端，离线设备过期或中继重启后由接入端重新注册恢复同一码。仍是双方主动出站连接、单控制端、一次性短期票据。停止共享即关闭控制连接并撤销本次注册，但不删除身份，下次开启恢复同一码。

## 运维

- 首次从旧版随机码升级需换一次新码；之后主机重启、进程重启、更新程序、中继重启不再换码。
- 中继和共享端均需 0.6.0。中继兼容旧注册；新版共享端遇到旧中继会明确要求升级，不悄悄退回随机码。现有远程控制协议兼容新长码。
- 身份文件默认放在用户本地应用数据目录 FurtherAgent/identities，按中继地址和设备名分文件，不放发布目录。
- 服务器推荐显式设置 `FURTHERAGENT_IDENTITY_FILE=/home/ubuntu/.config/furtheragent/hermes-default.identity`，这样修改设备名、回源地址或程序目录也保留同一身份。多个独立接入端必须使用不同文件。
- 身份文件要保留并受限备份；丢失文件无法恢复同一码。Linux 新建目录 700、新建身份文件 600；Windows 默认用户 LocalAppData，沿用用户目录权限。
- 同一身份有进程锁，不可同时启动两份，也不能在运行中执行离线重置。
- 有意换码：停止 Host 后使用原环境执行 `FurtherAgent.Host --reset-pairing`，再启动；WPF 设置页点击“重置本机配对码”会停止本机共享并更换身份。普通升级不要执行重置。恢复旧身份备份可重新注册旧码，所以重置后不要恢复旧文件。
- 固定码长期有效，应按连接凭据保管，不提交 Git、不放公开报告。不要自行设置简单密码或让多台设备共用密钥。

## 验证

123 项回环/协议检查通过，新增覆盖磁盘身份读回、接入端重启码不变、中继进程真实重启后原码重新连接、活动身份重置拒绝、显式重置换码、错误身份不能占原码、损坏身份文件失败而不悄悄换码。此前 16 位临时码协议的测试继续通过。

这些是本地真实回环服务验证，不代表公网中继已经切换。线上部署需要更新中继并迁移常用 Host，切换时现有连接会短暂断开；不要通过升级 Hermes 网关来做这件事。
