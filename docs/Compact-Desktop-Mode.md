# 桌面迷你模式

会话顶部的“收缩”按钮将同一窗口切换为迷你模式，默认 420×210。仅显示约五行上下文、输入框和发送按钮；上下文只显示用户与 AI 正文，不显示操作和附件面板。

- 按住顶部空白处拖动窗口，窗口边缘支持调整大小。
- 拖动上下文与输入区之间的分隔线调整上下文高度。
- 顶部左按钮收起/展开上下文，收起后高度约 110。
- 顶部右按钮还原原窗口位置、尺寸和最大化状态。
- 共用当前会话、输入草稿、发送逻辑和按钮可用状态；Ctrl+Enter 发送。
- 状态信息可悬停发送按钮查看，不单独显示功能区或状态栏。

没有另建连接或会话，不改变既有后台任务。迷你窗口位置单独保存到用户目录的 `compact-window.json`，拖动后延迟保存，还原时也会保存；下次收缩（包括重启程序后）恢复该位置，并限制在当前虚拟桌面范围内。此版本没有自动置顶配置。

验证：12 项迷你窗口实际控件检查、11 项中继发送/草稿检查、27 项 WPF/持久化检查通过。生成并查看 `artifacts/inspection/compact-ui.png`。输入区固定预留高度、清除主题外边距并增加浅色边框；上下文最大高度随面板尺寸限制，防止输入框被挤出窗口。验证覆盖大上下文缩小到最小窗口后输入框仍完整可见，以及位置落盘和重新读取。验证包含双向草稿绑定、发送确认后清空、正文过滤、折叠展开及还原；桌面鼠标拖拽和多显示器实际使用仍需安装后体验。
