# Android 0.9.5：取消内置语音密钥

按用户最新要求，移除自用版内置 Key 支持、资源读取代码和打包参数。APK 只使用用户在“连接 → 语音设置”中填写的 Key，通过手机 SecureStorage 保存。

未配置 Key 时点击语音会打开设置页。已有手机端保存的 Key 继续可用；仅依赖 0.9.4 内置 Key 的安装需要重新填写。0.9.5 / 905 可覆盖升级 0.9.4，无须修改服务器。

旧的 0.9.4 自用 APK 仍含内置 Key，本次改动不会更改已经生成或安装的旧包。应使用新的 0.9.5 APK。

语音协议和录音逻辑未变化。此前真实 API 联调已成功：8.565 秒合成中文音频，识别结果与原文一致；这不替代手机麦克风的实际验收。
